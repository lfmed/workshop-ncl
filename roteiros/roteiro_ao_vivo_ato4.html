Ato 4

Ao vivo no Genie Code

4.1 Conhecer os especialistas SQL editor → Genie Code

Prontos em lab_credito: resumo_carteira, quebra_carteira, evolucao_carteira, maiores_exposicoes e sinais_alerta.

@nuclea-monitoramento-credito Explique o que fazem as funções de workshop_nuclea_genie_catalog.lab_credito e rode quebra_carteira por UF e sinais_alerta para o ISPB 42691787, Varejo, Pequeno, Sudeste. Resuma os achados em uma tabela.
Mostre: o Genie Code lendo os COMMENTs das funções no Unity Catalog para entender cada especialista. “A documentação da função é o manual do agente.”
Checkpoint: quebra_carteira por UF dá SP 64,3%, MG 17,9%, RJ 13,8% e ES 4,0% do saldo, com MG a 4,51% contra 3,10% do mercado. sinais_alerta traz no topo Gonçalves da Mota (8 pontos: inadimplente, score caiu 116 pontos, boleto adulterado).

4.2 Conferir os números SQL editor → Genie Code

Valide os agentes: compare lado a lado lab_credito.resumo_carteira('42691787','Varejo','Pequeno','Sudeste') com um SQL direto sobre carteira_contratos com os mesmos filtros (porte MEI/ME/EPP, UF SP/RJ/MG/ES, status diferente de Liquidado). Mostre a diferença de cada métrica.
Fala: “Agente sem validação não vai para cliente. Aqui a diferença é zero.”

4.3 Sala Genie de crédito (pronta) Genie → Nuclea - Monitoramento de Credito

  • Mostre em Configure: a tabela carteira_contratos, as instruções e as 5 SQL functions, que foram anexadas pela API porque a UI não permitiu.
  • Pergunte:
Para o ISPB 42691787: como está a minha carteira de crédito de empresas do segmento varejo, pequeno porte, com presença na região sudeste? Compare com o mercado.
Para o ISPB 42691787: quais tomadores de Varejo, pequeno porte, no Sudeste eu devo olhar primeiro e por quê?
Esperado: a sala chama resumo_carteira e depois sinais_alerta (abra o SQL gerado e mostre a função sendo usada). Minha carteira: 622 contratos, R$ 27,92 mi e 4,02%; mercado: 6.258 contratos, R$ 260,33 mi e 4,64%. Gonçalves da Mota no topo dos sinais.

4.4 O time de agentes: Supervisor Agents → Supervisor Agent

  • Nome supervisor-credito-nuclea. Subagentes: a sala de crédito (já com as funções), Nuclea - Risco e Fraude e Nuclea - Boletos (PCR e SILOC). Ferramentas: as 5 funções de lab_credito e lab_ml.score_cnpj. Em Instructions, cole:
Você é o orquestrador de monitoramento de crédito da Núclea. Coordene especialistas: - Carteira (resumo, quebra, safras), Exposição (maiores tomadores), Alerta Precoce (sinais_alerta): UC functions; - Investigador: salas Genie de Risco e Boletos, apenas para 1 a 3 CNPJs críticos; - Score ML: score_cnpj para os maiores tomadores e os que têm sinais de alerta. Nunca invente números; chame as ferramentas antes de responder e compare sempre com o mercado. Formato: Resumo executivo; Indicadores vs mercado; Tendência (safras); Concentração; Sinais de alerta; Recomendações.
Sou a instituição ISPB 42691787. Como está a minha carteira de crédito de empresas do segmento varejo, pequeno porte, com presença na região sudeste? Depois investigue os 2 tomadores mais críticos em boletos e risco e me dê o score do modelo de cada um.
Se a UI não aceitar UC functions como ferramentas: use só as salas Genie como subagentes. A sala de crédito já contém as 5 funções.
Clímax: abra o trace e mostre quais especialistas foram acionados e com quais filtros. “O cientista não precisou estar na sala.”

4.5 O próprio Genie Code como agente de crédito Genie Code → Settings → MCP → UC Functions

Adicione as funções de workshop_nuclea_genie_catalog.lab_credito como servidor MCP. Depois, no painel do Genie Code:

@nuclea-monitoramento-credito Usando as ferramentas de lab_credito, quais tomadores da carteira do ISPB 42691787 (Varejo, pequeno porte, Sudeste) eu devo olhar primeiro e por quê? Monte uma tabela com saldo, sinais e ação recomendada.
Esperado entre os destaques: Novais Moreira S.A. (score caiu 173 pontos, faixa D, 2 alertas em aberto) e Gonçalves da Mota (inadimplente, com boleto adulterado confirmado).

Fechamento (5 min) Google Slides 18–21

  • Governança: cada instituição vê só a própria carteira e os agregados de mercado. No produto, o ISPB vem do login, nunca do LLM. A permissão EXECUTE vale igual para pessoas e agentes.
